### 2.2 版本兼容性

> **官方警告**（来自 creativevideotips 实测）：
> "The correct version of PostgreSQL comes with Resolve Project Server. It's an old version, but don't be tempted to get the newest version on your own. That won't work."

- DR 自带 Project Server 内含特定旧版 PG
- 自行升级 PG 大版本会导致 DR 无法连接
- DR 20 官方支持 PG 13（我们匹配 ✅）

### 2.3 我们是用 PG Project Server 还是直连 PG？

我们用的是**直连 PG**（Docker PG 13.4），不是 DR 自带的 Project Server 程序。区别：

| | Project Server（DR 自带） | 直连 PG（我们） |
|---|---|---|
| PG 版本 | DR 决定的特定旧版 | 我们控制（13.4） |
| 管理界面 | DR Project Server UI（GUI） | pgAdmin / psql |
| 访问密钥 | 程序内生成 `.davincikey` 文件 | 需手动配置连接 |
| 备份 | 无内置方案 | pg_dump 自管 |

**结论**：我们的直连 PG 方案更灵活，但失去了 Project Server GUI 的便利（访问密钥分发、UI 管理）。

## 三、Bin / 时间线 / 片段锁定机制

这是协作工作流的核心。不同页面有不同的锁定粒度。

### 3.1 锁定规则矩阵

| 页面 | 锁定粒度 | 第一人 | 其他人 | 机制 |
|------|---------|--------|--------|------|
| **Edit (剪辑)** | 整个时间线 | 读写 | 只读 | 时间线锁定 |
| **Fairlight (音频)** | 整个时间线 | 读写 | 只读 | 时间线锁定 |
| **Color (调色)** | 单个片段 | 读写 | 只读 | 片段级锁定 |
| **Fusion (特效)** | 单个片段 | 读写 | 只读 | 片段级锁定 |
| **Deliver (交付)** | Bin | 读写 | 只读 | Bin 锁定 |

### 3.2 锁定行为

- **自动锁定**：第一个打开 Bin/时间线/片段的人获得读写锁
- **自动释放**：离开后立即解锁
- **手动锁定**：右键 → Lock Bins（保持控制权）
- **只读进入**：Option + 点击 Bin（即使第一个进入也只读）

### 3.3 对我们团队的实际影响

我们 20 人团队中：
- 多个剪辑师同时开同一个项目 → 时间线锁定阻止并发编辑 → 需要分任务到不同时间线
- 调色师和剪辑师同时工作 → 片段级锁定，互不干扰 ✅
- 调色师和 Fusion 特效师可以同时处理**同一个镜头**（各自独立管理修改）

### 3.4 冲突解决

- 如果剪辑师占用时间线、调色师需要调某片段 → 调色师复制片段到自己的 Bin 中操作
- 内建聊天功能：右下角聊天窗口，不需互联网，纯局域网通信

## 四、共享存储（SMB）

### 4.1 我们已有

- SMB 服务器：`192.168.1.154`，共享名 `MYJC`
- 19 台 Mac mini 均通过 `/Volumes/MYJC` 挂载
- 素材路径统一，所有机器看到的路径一致

### 4.2 协作场景下的素材管理

**关键要求**：所有协作机器看到**相同的文件路径**。

我们已满足 ✅ — 所有机器挂载到相同路径 `/Volumes/MYJC`。

### 4.3 带宽考量

千兆以太网（1GbE）：
- 理论 125 MB/s，实际 ~75-95 MB/s
- 单路 4K ProRes 422 HQ ≈ 90 MB/s → 一个人就占满
- 多人同时播放高码率素材 → 必卡

**解决方案**（分级）：
1. **代理工作流**（推荐）：2K ProRes Proxy ≈ 20-30 MB/s → 3-4 人同时播放不卡
2. **本地缓存**：DR 渲染缓存写本地 SSD，不占网络
3. **升级网络**：10GbE 到交换机 + 主链路（长期方案）

## 六、访问密钥分发（直连 PG 环境）

Project Server 模式下通过 `.davincikey` 文件分发。但我们直连 PG → 每台机器需手动配置连接。

### 6.1 新机器加入协作的步骤

```
1. 打开 DR → 项目管理器
2. 左上角 "新建数据库" → 连接 → 选择 PostgreSQL
3. 输入：
   - 主机: 192.168.1.154
   - 端口: 5432
   - 数据库: MYJC_2026_A
   - 用户: postgres
   - 密码: DaVinci
4. 创建标签 → 连接
```

### 6.2 运维自动化思路

新机部署时可在 `deploy_new_machine.sh` 中自动配置此连接（写入 DR 偏好文件）。

## 七、协作项目创建流程

```
1. 服务器端: PG 已运行，数据库已创建
2. 任一客户端: 创建新项目
3. File → Enable Collaboration（启用协作）
   ↓ 触发效果:
   - Live Save 自动开启（每次点击实时保存）
   - 锁定机制启用
   - 聊天窗口可用
4. 其他客户端: 打开同一数据库 → 看到该项目 → 点击进入
```
