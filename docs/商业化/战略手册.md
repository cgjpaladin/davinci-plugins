## 二、你的"隐秘优势"：比想象中值钱的东西

在列出风险之前，先说清楚你手里真正值钱的是什么：

### 2.1 共享基础设施（最被低估的资产）

你的 `shared/` 目录（99个Python文件）不是"工具库"——它是一个**DaVinci Resolve 插件开发框架**：

- `pipeline_base.py` — 通用异步处理流水线（上传→提交→轮询→下载→应用）
- `product_registry.py` — 多产品统一注册、版本管理、售卖控制
- `pricing.py` / `pricing_defaults.py` — 多供应商计费抽象层
- `interface.py` — 达芬奇原生UI框架（进度条、状态栏、日志）
- `ledger.py` — 消费记账与审计
- `llm_providers.py` / `llm_typo_check.py` — LLM集成抽象层
- `adapters/` 模式 — 供应商可插拔架构

**这意味着什么？** 别人开发一个新插件要从零搭架子。你在 `shared/` 之上开发新插件，只需要写业务逻辑——AI换口型、AI语音克隆这些"调研完成"的项目，**开发周期可以从 6 个月压缩到 6 周**。

这本身就是竞争壁垒。

### 2.2 领域知识的深度

你不是在做"通用 AI 视频工具"，你是在做**短剧后期工业流水线**。这体现在：

- EP/SC/GR/TK 的命名规范（不是随便起的，是对标行业拍摄流程）
- 双供应商降级（无痕AI + 鬼手）——理解生产环境的容错需求
- 缓存命中 + 撤销替换 —— 理解剪辑师"反复试"的工作习惯
- OSS 中转 + 本地下载 —— 理解国内网络环境和文件管理的实际约束
- 定价精确到 `point_to_yuan()` —— 成本敏感型的商业思维

**这种领域深度，硅谷的 AI 创业公司做不到。他们不懂短剧生产流程。**

### 2.3 设计系统的统一性

`DESIGN.md` 不是一份"风格指南"，它是一个完整的**达芬奇原生 UI 设计系统**——色彩、排版、间距、组件、交互规范全部量化。这意味着：

- 所有插件有统一的专业外观（不像开源工具的拼凑感）
- 新插件可以直接复用 UI 模板
- 对外销售时有品牌识别度

## 三、市场机会：三个圈层的收入模型

### 3.1 圈层一：你的"自留地"——短剧后期制作团队

**市场规模**：
- 中国短剧出海应用 2025 年下载量 14.93 亿次，占全球 80%
- 海外短剧市场 2025 年 40 亿美元，2026 年预计超 50 亿美元
- 短剧制作以"快"为核心——单集 1-3 分钟，整部上百集，制作周期数周

**你的机会**：
短剧制作的核心瓶颈是**后期效率**。去字幕（为重新配音）、换口型（多语言本地化）、语音克隆（改词补配）——这三样恰好覆盖了短剧后期最耗时的三个环节。

**可触达市场规模（SOM）估算**：
- 假设国内短剧制作团队约 2,000-3,000 家（含 MCN 机构的制作部门）
- 使用 DaVinci Resolve 的比例约 5-10%（实际可能更高，因为 Resolve 免费版对中小团队友好）
- 即 **100-300 个团队**是达芬奇 + 短剧的交叉用户
- 如果每个团队年均付费 ¥3,000-8,000，这个圈层的 TAM 约为 **¥30 万-240 万/年**

> ⚠️ 实话：这个圈层不大。但它是你最容易赢的圈层——你懂他们的工作流，他们需要你的工具。

### 3.2 圈层二：泛影视后期——DaVinci Resolve 插件市场

**市场规模**：
- DaVinci Resolve 全球市场占有率约 15%，在专业视频编辑软件中排第三（仅次于 Premiere Pro 35%、Final Cut Pro 25%）
- 约 23,000+ 企业用户使用 DaVinci Resolve
- 活跃个人/自由职业者用户估计在 **200万-500万** 级别

**你的机会**：
- FireCut AI（你在这个市场最直接的参照物）定价 $17-34/月，做的是"AI 剪辑自动化"
- Dehancer Pro、Neat Video 等专业插件定价 $100-400 一次性买断
- **AI去字幕** 在这个市场几乎没有直接的达芬奇原生插件竞品
- **批量命名工具** 的竞品更多是通用文件管理工具，而非达芬奇原生工具

**可触达市场规模**：
- 假设全球 DaVinci Resolve 活跃用户 300 万
- 其中愿意为第三方插件付费的比例约 3-5%（参考 AE 插件市场渗透率）
- 即 **9-15 万付费用户**
- 如果捕获 0.5-1%，即 **450-1,500 个付费用户**
- 单个产品定价 $29-99 一次性 / $5-15/月订阅

**这个圈层的关键问题是**：你是否愿意做英文版、英文文档、英文客服？

### 3.3 圈层三：B2B 企业定制 / 私有化部署

**机会描述**：
- 中大型短剧/MCN 机构（如九州、点众、中文在线等）有定制化需求
- 他们愿意为"专属工具 + 私有化部署 + SLA 保障"付费
- 单笔订单可能在 **¥5 万-50 万** 级别

**你的优势**：
- 你的 shared/ 架构天然支持私有化部署（.env 配置、本地 API、无云端依赖）
- 已有的客户验证（"推全公司验证 ✅ v1.6.0"）

**这个圈层的挑战**：
- 需要商务能力（BD、招投标、合同谈判）
- 需要售后支持体系
- 定制需求可能分散研发精力

2. **架构壁垒**：shared/ 基础框架的复用效率，让后来者难以追赶开发速度
3. **领域深度**：短剧工作流的理解不是看几篇报告就能获得的
4. **设计一致性**：达芬奇原生 UI 设计系统让产品有"官方插件"的质感

## 五、商业模式：怎么收钱

### 5.1 三种可选模式

#### 模式 A：订阅制（SaaS 化）

```
个人版：¥29/月 或 ¥199/年
  - AI去字幕（月处理上限 200 分钟）
  - 交付自检（基础版）
  - 社区支持

专业版：¥79/月 或 ¥599/年
  - AI去字幕（月处理上限 1,000 分钟）
  - 交付自检（完整版 + LLM 字幕校对）
  - 批量命名工具
  - 邮件支持

团队版：¥199/月/5席位
  - 全部产品
  - 优先支持
  - 用量共享池
```

**优点**：持续收入、可预测、容易规模化
**缺点**：需要防破解/授权管理系统、用户抗拒月费

#### 模式 B：一次性买断 + 大版本升级收费

```
AI去字幕：¥299 永久（含1年更新）
交付自检：¥199 永久（含1年更新）
批量命名：¥99 永久（含1年更新）

全套打包：¥499（比单买省 ¥98）
大版本升级：原价 50%

未来新产品（换口型/语音克隆）：¥399-599 每个
```

**优点**：符合工具类软件的消费心理、一次开发持续卖
**缺点**：需要持续拉新才能增长、老用户升级收入不稳定

#### 模式 C：B2B 项目制定价

```
基础部署包：¥9,800
  - 2个产品授权（5席位）
  - 远程安装 + 1小时培训

企业定制包：¥28,000-68,000
  - 全产品授权（20席位）
  - 私有化部署 + 定制配置
  - 3个月技术支持 + SLA

年度维护费：合同金额的 20%
```

**优点**：单笔收入高、客户粘性强
**缺点**：销售周期长、需要商务能力

### 5.2 推荐策略：B + C 混合

**短期（0-6个月）**：个人/小团队买断制为主
- AI去字幕 ¥299，交付自检 ¥199，打包 ¥399
- 在 B站、剪辑社群、达芬奇中文论坛推广
- 目标：**前 6 个月 50-100 个付费用户**，验证付费意愿

**中期（6-18个月）**：拓展企业客户
- 当个人用户中有 MCN/制作公司的人时，自然产生企业需求
- 提供团队版买断（¥2,999/5席位起）
- 逐步增加企业定制项目

**长期（18个月+）**：转向订阅制
- 当产品矩阵达到 5+ 个产品时，订阅制的价值感知更强
- 老买断用户保留终身使用权，新用户只提供订阅选项
- 可以考虑按月 + 按年混合

## 六、进入市场路径：第一批客户从哪来

### 6.1 你的独特渠道优势

你有一个别人没有的东西：**你已经在用这些工具做实际生产了**。

这意味着：
- 案例不是编的——"我们用 AI去字幕 处理了 XX 集短剧，节省了 XX 小时"
- Demo 不是做的——展示你实际的工作流
- 口碑不是买的——你身边就有同行需要这些工具

### 6.2 推荐路径

**第 1 步：打造一个"产品官网"级别的 Landing Page**
- 不是淘宝店，不是公众号文章，是一个独立的产品页面
- 参考：FireCut.ai、Dehancer.com 的产品页
- 包含：产品截图/GIF、使用场景、定价、FAQ
- 用 impeccable 技能可以快速搭建

**第 2 步：制作 3-5 个"真实场景"演示视频**
- "短剧去字幕：从选中片段到替换完成，全程 2 分钟"
- "交付自检：5 分钟排查一条时间线的所有问题"
- 发布到 B站、抖音、视频号

**第 3 步：在精准渠道投放内容**
- 达芬奇中文社区（贴吧、知识星球）
- B站达芬奇教程评论区（"up主，你视频里去字幕用了多久？我有更快的方法"）
- 微信剪辑师/后期群
- We Suck Less 论坛（全球最大的达芬奇社区，可以发英文贴）

**第 4 步：免费增值（Freemium）策略**
- AI去字幕：免费版每月 30 分钟处理额度
- 交付自检：免费版检查轨道/字幕，付费版增加音频/黑帧/LLM校对
- 批量命名：免费版限制 10 个文件/次

**第 5 步：从免费用户中转化**
- 用量达到上限 → 推送升级提示
- 收集用户反馈 → 快速迭代 → 积累口碑
- 找到"超级用户" → 发展为种子客户和推荐人

## 七、风险与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|:----:|:----:|----------|
| **市场规模太小**（达芬奇+短剧交叉用户不足） | 🟠 中 | 高 | 不要只做短剧。去字幕、自检这些工具的适用场景远超短剧——YouTube、企业宣传片、课程视频等都需要 |

| **API 供应商涨价或关闭** | 🟡 中 | 中 | 已有多供应商降级机制。继续增加供应商适配（火山引擎、阿里云等） |
| **盗版/破解** | 🟠 中高 | 中 | 个人版不必严防（盗版用户本来也不会买）。企业版用硬件绑定 + 在线激活 |
| **个人精力瓶颈**（一个人开发+销售+支持） | 🔴 高 | 高 | 先只卖 AI去字幕 + 交付自检，不要贪多。定价要高到能支撑"雇人做客服" |
| **没有英文版，错过全球市场** | 🟡 中 | 中 | 先用中文市场验证 PMF（产品-市场匹配）。验证后再考虑国际化 |

## 八、推荐的"最小可行性商业化"路径

**不要试图一下子把 8 个产品都商业化。** 这是最常见的自杀式打法。

### Phase 1：验证（第 1-3 个月）

**只做一件事：把 AI去字幕 卖出去。**

- 制作 Landing Page + 3 个演示视频
- 定价：¥199 买断（前 50 个用户 ¥99 早鸟价）
- 在 3 个精准渠道投放内容
- 目标：**30 个付费用户**
- 成功指标：有人愿意付钱，且不是熟人

### Phase 2：扩展（第 3-6 个月）

**加入交付自检工具，形成"套装"概念。**

- AI去字幕 ¥299 + 交付自检 ¥199 = 套装 ¥399
- 开始在B站/公众号持续输出"达芬奇插件开发/使用"内容
- 目标：**累计 100 个付费用户**
- 成功指标：有陌生用户主动推荐给他人

### Phase 3：产品化（第 6-12 个月）

**启动 AI换口型 开发（利用 shared/ 架构的优势），配套企业定价。**

- 根据 Phase 1-2 的用户反馈打磨现有产品
- AI换口型 开发 + Beta 测试
- 推出企业版定价
- 目标：**累计 200-500 付费用户 + 2-3 个企业客户**

### Phase 4：规模化（第 12-24 个月）

**产品矩阵完善后，转向订阅制，考虑英文版。**

- 产品 ≥5 个时启动订阅制
- 根据用户数据决定是否做英文版
- 目标：**可维持全职投入的收入水平**

### 现实结语

**我对你的建议是：不要把这个当"创业项目"来融资。把它当成"独立开发者产品"来经营。**

你的优势是成本极低（一个人开发、无办公成本）、领域极深（短剧后期）、差异化明显（达芬奇原生集成）。月入 ¥5,000-20,000 在 6-12 个月内是可实现的目标。如果能做到 ¥20,000+/月，你已经跑赢了绝大多数独立开发者。

至于"做大做强"——那取决于你是否愿意做英文版、是否愿意雇人、是否愿意转型为"公司"而不是"工作室"。这些选择不着急做，先卖出去再说。
