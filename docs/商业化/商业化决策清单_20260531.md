## 四、崩溃上报案（重点待设计）

用户出问题后能**一键上传**到裁缝老师，而不是截图/复制粘贴。

难点：
- 达芬奇崩溃时插件进程已经死了，怎么收集日志？
- 用户可能没有网络或不会操作
- 怎么让上报过程极简（一个按钮）？
- 上报内容要包含什么？日志、机器配置、截图、操作步骤？

## 五、License 架构 MVP

```
安装 → 首次打开 → 记录试用开始日期
  ↓
＜30天：正常用，显示「试用第 X 天」
  ↓  
≥30天：锁定，只能点「购买 ¥99」
  ↓
用户买 → 拿 Key → 输入 → 后端校验 → 绑定机器 → 永久解锁
  ↓
换电脑/重装 → 用原 Key 重新激活（后端判断未超过授权设备数）
```
