## 二、OFX 插件开发架构（未来储备）

### 四层架构

```
OfxPlugin Entry (getPluginIDs)        ← 注册入口
  └── PluginFactory                   ← describe + createInstance
        └── ImageEffect               ← render + 参数绑定
              └── ImageProcessor      ← CPU多线程 / GPU内核
```

### GPU 渲染后端

| 平台 | 后端 | 文件 |
|------|------|------|
| macOS Apple Silicon | Metal | `MetalKernel.mm` |
| NVIDIA | CUDA | `CudaKernel.cu` |
| 通用 | OpenCL | `OpenCLKernel.cpp` |
| 纯CPU | 多线程 | `multiThreadProcessImages()` |

macOS 上首选 **Metal**（Apple Silicon 原生支持，性能最佳）。

### 编译安装

```bash
# 编译生成 .ofx.bundle
# 使用 Makefile 或 Xcode 项目

# 安装（需管理员权限）
sudo cp -R PluginName.ofx.bundle /Library/OFX/Plugins/
```

### OFX vs Fusion 脚本

| 维度 | OFX 插件 | Fusion 脚本 |
|------|----------|-------------|
| 语言 | C++ | Python / Lua |
| 作用域 | 达芬奇全局 | Fusion 页面内 |
| 能力 | 像素级图像处理、GPU加速 | 自动化操作、UI面板 |
| 安装位置 | `/Library/OFX/Plugins/` | `.../Fusion/Scripts/` |

**对我们**：如果未来 AI 超分/换口型需要实时预览，OFX 是唯一路径。当前 Python 脚本方案适合批处理。

## 三、AI 开发工具链（M4 Mac mini 可用）

### PyTorch MPS 加速

```bash
uv pip install torch torchvision torchaudio
```

```python
import torch
print(torch.backends.mps.is_available())  # True (Apple Silicon)
```

### MLX（Apple 原生 ML 框架）

Apple 专为 M 芯片设计，本地跑 LLM 首选。

```bash
uv pip install mlx mlx-lm
```

### 核心 AI 工具速查

| 工具 | 用途 | 我们的场景 |
|------|------|-----------|
| PyTorch + MPS | 深度学习训练/推理 | 换口型/语音克隆/超分 |

| ONNX Runtime | 跨平台推理 | 模型部署 |
| Core ML Tools | Apple生态部署 | iPhone/iPad端 |

### HCI 工具

| 领域 | 核心库 | 潜在用途 |
|------|--------|---------|
| 视觉 | OpenCV, MediaPipe | 人脸检测、手势识别 |

## 六、达芬奇 Python 路径优先级

达芬奇启动时按以下顺序查找 Python 3：

| 优先级 | 路径 | 来源 |
|:--:|------|------|
| 1 | `/Library/Frameworks/Python.framework/` | Python.org 官方安装（推荐） |
| 2 | `/usr/local/bin/python3` | Homebrew（Intel Mac） |
| 3 | `/opt/homebrew/bin/python3` | Homebrew（Apple Silicon Mac） |

Miniconda 的 Python **不被自动识别**。这解释了为什么我们的壳方案用框架版 Python 是对的。
