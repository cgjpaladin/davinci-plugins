📦 安装

1 解压 zip — 双击下载的 zip，Mac 自动解压成文件夹

⚠ 不要在压缩包里直接双击安装脚本！先在 Finder 里解压。

2 双击「Mac安装.command」

→ 终端弹出 → 检测 Python → 输入管理员密码 → ✅ 安装完成

⚙️ 配置（首次使用）

1 插件启动后，点击「开始检查」下方的 ⚙ 配置 按钮

2 DeepSeek API Key — AI 字幕校对用

去 platform.deepseek.com → API Keys 创建，粘贴过来

不填不影响其他功能，只无法使用 AI 校对。

3 飞书 App ID / Secret — 从飞书文档下载剧本用（如你通过飞书协作审稿）

创建方式：飞书开放平台 → 创建企业自建应用 → 获取 App ID 和 App Secret → 开启文档权限。

可选。团队内部用飞书协作才有用，个人用户可跳过。

4 个人词典 — 自定义屏蔽词和替换建议

点击「在 Finder 中定位」→ 右键 CSV → 打开方式 → WPS / Excel / Numbers → 编辑。左边写白名单（不检测），右边写黑名单+替换建议。

专为短剧行业定制：平台审核敏感词、公司特定术语、角色名等。
