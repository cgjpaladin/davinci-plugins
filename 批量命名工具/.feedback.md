#### 2. mock handler 时机错误导致首拖 36 文件
`if(!window.pywebview)` 在模块加载时执行，pywebview 还没注入 → mock handler 误注册
→ 挪到 init() 后，确认 pywebview 存在才判断 [→MEMORY#批量命名架构]

#### 3. WKWebView select 的 option value='' 陷阱
动态生成 `<option value="请选择">` 时 select 文本不可见，因为 WKWebView 对有值状态用原生渲染通道屏蔽 CSS
旧版 HTML 用 `value=""` 走「无值/占位」模式，CSS 才生效
→ SOUL#34：WKWebView select 占位项必须 value=""

#### 4. except:pass 吞掉 auto-check bug
auto-check 统计的是文件路径字符串而非文件大小 → TypeError 被 except:pass 无声吞掉
→ SOUL#27（已存在）再次被触发

#### 5. _lbs 未定义导致 renderList 崩溃
替换硬编码字段列表时，updButtons 定义了 _lbs，但 renderList 里也引用了同名变量 → ReferenceError
→ 动态变量谨慎跨函数共享

#### 6. f[d.key] vs d[fd.key] 变量名混淆
多次替换中把 d[fd.key]（defaults dict + field config key）误写成 f[d.key]（不存在的变量）
→ 批量替换后必须 git diff 验证
