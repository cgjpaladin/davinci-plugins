# 视频超分辨率（Super-Resolution）API 调研 — 短剧后期场景

## 背景（已确认，不需要反问）

- 短剧后期制作，需要把 720P 或低画质视频提升到 1080P/4K 交付标准
- 需要 API 集成到自动化工作流（不是手工用网页工具）
- 硬约束：国内网络直连，不翻墙
- 已有火山引擎 AK/SK

## 已掌握的候选方案

| 方案 | 已知 |
|---|---|
| 阿里云 视频超分辨 | 视觉智能平台，2倍放大，h264/MP4 输出 |
| 火山引擎 画质超分/极智超清 | 智能多媒体服务，已有AK/SK |
| 腾讯云 画质增强 | 数据万象，含超分+色彩增强+插帧 |
| 七牛云 视频超分 | 按输出时长计费，2K规格 |
| Real-ESRGAN / Video2X | 开源，需GPU本地部署 |

## 调研任务

### 一、API 方案详情

对每个云端方案（阿里/火山/腾讯/七牛），逐一回答：

| 维度 | 要求 |
|---|---|
| API 文档 URL | 直接给链接 |
| 缩放倍数 | 2x？4x？固定还是可选？ |
| 输入支持 | 分辨率上限？时长上限？文件大小上限？ |
| 输出格式 | 编码格式？是否保持原帧率？ |
| 画质增强 | 只是拉分辨率，还是同时做去噪/去伪影/锐化？ |
| 处理速度 | 1分钟视频要多久？ |
| 价格 | 按输出时长计费？按分辨率计费？给场景算账：1集1.5分钟×100集 |
| 批量/并发 | QPS 限制？ |

### 二、短剧场景实测指标

1. **720P → 1080P**：最常见场景，效果能不能看？
2. **1080P → 4K**：偶尔需要，效果如何？
3. **人物特写**：短剧大量人物近景，超分后人脸会不会出现"塑料感"？
4. **字幕/文字**：画面里有硬字幕时，超分后文字边缘是否清晰？
