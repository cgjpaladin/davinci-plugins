# AI视频去水印/去字幕技术调研报告（2025-2026）

## Executive Summary

本报告针对AI视频去水印/去字幕领域进行全景扫描与深度调研，覆盖国内外主要API服务商、开源方案、短剧行业现状以及DaVinci Resolve集成可行性。研究发现，当前市场呈现"云端API服务主导、开源方案快速追赶"的双轨格局。国内市场以水印云、无痕AI为代表，主打本地化运营和中文硬字幕处理能力；阿里云、腾讯智影等大厂则通过图像修复API切入细分场景。国际市场上HitPaw、Runway等产品占据一席之地，而GitHub上以Video-Subtitle-Remover（星标10.6k）为代表的开源项目已具备较高可用性。价格方面，国内外服务差异显著，从免费到每分钟数十元不等。DaVinci Resolve暂无原生去水印插件，但通过Python API可实现"选中片段→导出→API处理→回插"的半自动化工作流。短剧行业对AI去水印/字幕的需求正快速爆发，但现有方案在时序一致性、动态水印追踪等技术上仍有较大优化空间。

## 1. Introduction

### 1.1 Research Background

2025年以来，短视频二创、跨境内容适配以及AI生成视频的爆发式增长，共同催生了大量视频去水印/去字幕需求。据行业数据显示，专业创作者每周平均花费4.2小时处理水印问题，而传统裁剪法易损失画面，已无法满足精细化创作需求[1]。AI技术的深度卷积神经网络、运动预测算法等技术的迭代，让"精准识别+无痕修复"成为可能，2025年的视频去水印工具实现了处理效果与效率的双重突破。

### 1.2 Research Objectives

本报告旨在回答以下关键问题：市场上有哪些可用的AI视频去水印/去字幕方案？各方案的技术路线、功能特性和价格如何？针对中文硬字幕场景，哪些方案表现最优？如何与DaVinci Resolve实现集成？短剧行业的实际需求和痛点是什么？

### 1.3 Research Methodology

本报告采用多源信息交叉验证法：(1) 通过批量搜索覆盖国内外主要服务商官网、行业测评、技术文档；(2) 对重点网站进行深度内容提取；(3) 交叉比对多项数据源以确保信息准确性；(4) 所有信息标注获取日期，优先采用2025-2026年数据。

### 2.3 开源方案

#### 2.3.1 Video-Subtitle-Remover (VSR)

**GitHub信息**：https://github.com/YaoFANGUK/video-subtitle-remover，星标10.6k，Fork 1.4k[14]。

**核心功能**：
- 无损分辨率将视频中的硬字幕去除
- AI区域填充：超强AI算法模型对去除字幕文本区域进行填充（非马赛克）
- 字幕提取：可提取原视频字幕，配合VSE使用
- 自定义位置：支持自定义字幕位置
- 全视频自动去除：支持全视频自动去除所有文本
- 批量图片处理：支持多选图片批量去除水印

**技术实现**：
- 支持模式：CUDA（NVIDIA）、DirectML（AMD/Intel）、CPU、macOS Apple Silicon
- 去除算法：STTN（真人视频效果好速度快）、LAMA（图片效果最好，动画类视频效果好）、ProPainter（运动剧烈视频效果好，消耗大量显存）、OpenCV（基础算法）[14]

**部署要求**：
- Python 3.12+
- PaddlePaddle 3.0.0
- PyTorch 2.7.0
- CUDA 11.8/12.6/12.8（根据GPU选择）

**预构建包**：提供Windows CPU/DirectML/NVIDIA CUDA版本下载，开箱即用[14]。

**使用方式**：
- 图形界面：`python gui.py`
- 命令行：`python ./backend/main.py -i <输入视频> -o <输出视频>` [14]

## 6. DaVinci Resolve集成可行性分析

### 6.1 Resolve Python API工作流分析

DaVinci Resolve提供Python/Fu脚本 API支持，可在免费版和Studio版中使用。当前版本为DaVinci Resolve 19/20（2025年持续更新），具备以下自动化能力[16]：

**媒体管理**：通过Python API可以访问媒体池、读取文件元数据、选择特定片段。

**时间线操作**：支持读取/修改时间线内容、导出特定片段、插入处理后的素材。

**色彩与特效**：Fu脚本可以调用Fusion页面功能，但原生去水印能力有限。

**推荐工作流**：
```
1. 在Resolve中选中需要去水印的片段
2. 通过Python API将片段导出为临时视频文件
3. 调用外部去水印API（如无痕AI、阿里云万相等）处理视频
4. 将处理后的视频通过API重新导入时间线
5. 将原片段替换为处理后的干净版本
```

### 6.2 技术可行性评估

**导出/导入能力**：Resolve支持通过Python API执行`DaVinciResolveScripting`的片段导出和媒体池操作，可以实现半自动化流程。

**色彩空间兼容性**：处理时需注意保持原始色彩空间（YRGB、Rec.709/2020等），避免色偏；建议输出与输入保持相同编码格式。

**时码同步**：关键挑战在于处理后的视频需要与原始时间线精确对齐，包括帧率、分辨率、时码对应关系。

**潜在风险点**：
- 片段重新导入后可能需要手动对齐，特别是处理后视频存在帧率或码率变化时
- 处理过程中原始素材的代理或缓存管理需要额外注意
- Fusion页面虽可实现基本修复，但缺乏AI去水印专业能力

### 6.3 替代方案：Resolve + 开源工具联动

可以考虑将Video-Subtitle-Remover与Resolve联动：

1. 在Resolve中导出需要处理的片段
2. 使用Video-Subtitle-Remover进行本地AI处理（保护隐私，无API费用）
3. 将处理结果回插到Resolve时间线

这种方案的优势是完全本地化、无API费用，适合对数据隐私有要求的企业；劣势是需要较高配置的GPU工作站，且处理速度受限于本地硬件。

### 6.4 达芬奇去水印插件现状

**市场现状**：据调研，暂无成熟的DaVinci Resolve原生去水印插件。传统去水印主要通过以下方式实现：
- 模糊/马赛克遮挡：简单但效果差
- 裁剪：损失画面内容
- 手绘遮罩：费时费力
- Fusion页面文字消除：有限能力

**专业建议**：如需在Resolve内实现去水印，当前最可行方案是通过Python脚本调用外部API或本地AI工具，将处理结果回插时间线。
