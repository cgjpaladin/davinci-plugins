# AI声音克隆方案调研 — 短剧后期配音

## 你的信息我已经有了，直接开始调研，不要反问

以下是你需要知道的全部背景，不要再问我确认：

- **现状**：团队在用 sovits.cn 网页端（纯手工上传下载），没有接 API。每年充几百块会员，不限量使用。
- **痛点**：网页端效率太低，每次要手动上传音频→等克隆→输入文本→下载→导入达芬奇。想换成有 API 的方案，让工作流自动化。
- **语言**：主要是标准普通话。但方言（东北话、四川话、粤语等）也会有需求，方言方案请单独列出。
- **最看重的**：情感还原度排第一。不是念新闻，是演员在吵架、哭戏、耳语——情绪到了声线要有变化。
- **时间要求**：不追求实时，一天之内能完成一代剧的配音就行。
- **不需要**：变声、背景音效、混音等额外处理。只要干净的人声克隆+TTS。
- **硬约束**：国内网络直连，不需要翻墙。团队20人，都没梯子。

## 调研任务

### 一、API 详情（每个方案）


| 维度 | 要查清楚 |
|---|---|
| API 文档 URL | 直接给链接 |
| 克隆最少需要几秒音频 | 对录音环境有要求吗？手机录的行不行？ |
| 情感控制 | 能否指定情感（愤怒/悲伤/兴奋/耳语）？ |
| 长文本是否稳定 | 几百字连续对白会不会越说越崩？ |
| 输出格式 | 采样率、格式、是否流式？ |
| 多角色管理 | 能否创建多个声音模型并随时切换？ |
| 价格 | 给短剧场景算账：1 集约 1000 字对白 × 100 集 = 多少钱 |
| 并发/QPS | 批量生成限制？ |

### 二、方言方案（单独一节）

如果平台支持方言克隆，列出：
- 支持哪些方言？
- 是需要方言原声素材来克隆，还是直接用 TTS 选方言音色？
- 效果评测？

### 三、短剧实战评分

每个方案从以下维度打分（1-5分）：

| 维度 | 说明 |
|---|---|
| 情感还原 | 吵架/哭戏/悄悄话的表现力 |
| 克隆效率 | 从录音到可用模型要多久 |
| API 易用性 | 文档清晰度、SDK 支持 |
| 性价比 | 100 集的成本 |
| 稳定性 | 服务可用率、长文本不崩 |

### 四、最终推荐

- **推荐方案**（只能选一个）：说明为什么它最适合短剧后期配音
- **与 sovits.cn 对比**：换了之后到底好在哪？列 3 个最关键提升
- **备选方案**：如果第一选择不行，第二选谁？
