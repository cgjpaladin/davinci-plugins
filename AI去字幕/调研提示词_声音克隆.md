# AI声音克隆（Voice Cloning）方案调研 — 短剧后期配音场景

## 硬约束

**所有方案必须国内网络直连可用，不需要翻墙。** 团队20个剪辑师都没有梯子。

## 场景说明

短剧后期制作：改完台词后需要AI生成演员的声音来替换原声。不是简单的"文字转语音"，而是要**还原演员的表演**——愤怒、哭泣、耳语、急促对白，这些情感细节必须到位。

## 核心调研问题

### 一、API方案详细对比

对每一个有API的方案（火山/阿里/FishAudio/腾讯/sovits.cn），逐一给出：

| 维度 | 要求 |
|---|---|
| 官方API文档链接 | 直接给URL |
| 克隆所需音频 | 最短多少秒？对录音质量要求？ |
| 情感控制 | 能否指定情感（愤怒/悲伤/兴奋/平静）？能否调节语速、音调？ |
| 长文本稳定性 | 几百字连续对白会不会越来越崩？ |
| 中文口音支持 | 方言？带口音的普通话？ |
| 音色一致性 | 同一个人物多次调用，声音是否一致？ |
| 输出格式 | 采样率？WAV/MP3？是否支持流式输出？ |
| 价格 | 按字符/按秒/按次？给短剧场景估算：1集约1000字对白，100集 |
| 并发限制 | QPS？批量生成？ |

### 二、短剧场景实战评估

请从短剧后期配音的实际需求出发，评估：

1. **情感还原度**：这不是念新闻稿——演员在吵架/哭戏/悄悄话时，克隆的声音能不能还原那种情感张力？
2. **同剧多角色**：一部剧有男主、女主、配角，需要为每个人创建独立的声音模型。各方案是否支持管理多个声音模型？
3. **与sovits.cn对比**：作为已经在用sovits.cn的团队，换了火山/阿里/FishAudio之后，到底好在哪？列出3个最关键的提升点。
4. **换口型联动**：如果后续要配合AI换口型（视频唇形同步），哪个声音克隆方案生成的音频最适合驱动口型模型？
