## 二、各方案实测详情

### 🥇 火山引擎 VOD — 质量+价格最优

| 维度 | 结论 |
|------|------|
| 产品 | VOD 精细化字幕擦除（DiT 大模型） |
| 价格 | **¥1.00/分钟** |
| 实测质量 | ✅ 裁缝老师确认满意，720×1280 输出 |
| 处理速度 | 15秒测试视频约 4 分钟完成 |
| 接入复杂度 | ⚠️ 高：自定义 HMAC-SHA256 签名，SDK 有 bug，需手写 |
| 签名铁律 | Host=`vod.volcengineapi.com`, Region=`cn-north-1`, 不是标准 AWS SigV4 |
| 产物下载 | ⚠️ 需绑定加速域名，或通过 DirectUrl 手动下载 |
| 适配器状态 | ⏳ 待基于 `test_vod_official.py` 重写 |

**结论**：效果最好，价格合理。接入踩坑一次后稳定可用。是取代鬼手的最佳候选。

---

### 🥈 鬼手 GhostCut — 当前主力

| 维度 | 结论 |
|------|------|
| 产品 | 去字幕，支持 basic/lite/pro/pro_box 四档 |
| 价格 | basic ¥0.50 / lite ¥1.00 / pro_box ¥1.90（主力模式） |
| 适配器 | ✅ `adapters/ghostcut.py` 完成，456 行 |
| 签名方式 | 双重 MD5（极简，2行代码） |
| 文件上传 | 自动上传到鬼手 OSS → 临时 URL |
| 团队部署 | ✅ 零依赖，纯 urllib，全国剪辑师拿到就跑 |

**结论**：已验证的生产方案。pro_box 模式 ¥1.90，比火山贵近一倍但零运维成本。

---

### 🥉 无痕AI Clipflow — 最有潜力的新方案

| 维度 | 结论 |
|------|------|
| 公司 | 杭州岁羽网络科技有限公司 |
| 产品 | 视频去字幕，支持无痕/极速两种模式 |
| 计费 | 积分制：无痕 3积分/30秒，极速 2积分/30秒 |
| 去字幕模式 | 无痕（algorithm=1，智能识别，1个区域）；极速（algorithm=0，1-3个区域） |
| 适配器 | ✅ `adapters/clipflow.py` 完成，456 行 |
| API 流程 | 创建任务→设置规则→添加素材→启动→轮询→下载 |
| 文件上传 | ✅ 支持本地文件直传 OSS |
| 当前状态 | ⏳ 适配器已写完，待裁缝老师注册获取 API Key 后实测 |

**结论**：流程比鬼手复杂（5步 vs 2步），但对用户透明。积分制灵活性高。待实测验证去字幕质量。

### ❌ 阿里云 — 已淘汰

| 维度 | 结论 |
|------|------|
| 产品 | 视觉智能 EraseVideoSubtitles |
| 价格 | ¥0.40/分钟（最便宜） |

**结论**：价格最低但效果零。已从候选名单移除。

---

### 开拍 kaipai.com — 不适合集成

| 维度 | 结论 |
|------|------|
| 技术 | 美图自研（MiracleVision + MTADiffusion），非第三方 API |
| API | ❌ 无独立开发者 API，企业需走美图 AI 开放平台另开户 |
| 免费版限制 | 60秒/1080P，完全不够短剧场景 |
| 适用场景 | 个人手工处理几条视频，不适合批量自动化 |
| 调研来源 | 豆包 108KB + GPT Deep Research 15KB，交叉验证一致 |
