# AI视频换口型（Lip-Sync）技术调研任务

## 背景

我是短剧后期制作团队，需要在视频中替换演员的口型以匹配新的配音内容（类似中文配音替换或多语言配音场景）。需要调研市场上可用的AI换口型API服务和开源模型方案。

## 调研要求

### 一、API服务商调研（重点）

请按以下维度逐一调研至少5家提供AI视频换口型API服务的公司：

| 维度 | 需要查清 |
|---|---|
| 公司名称 + 产品名 | 全称 / 官网 |
| 核心技术路线 | 自研模型？基于哪个开源模型？ |
| API可用性 | 是否对外开放API？申请流程？ |
| 输入要求 | 视频格式、分辨率限制、时长限制、是否需要音频 |
| 输出效果 | 分辨率支持、处理速度（分钟/秒）、口型准确度 |
| 价格 | 按秒/分钟/积分？有没有免费额度？ |
| 中文支持 | 对中文口型效果如何？有没有专门优化？ |
| 批量处理 | 是否支持批量？并发限制？ |

**必须覆盖的候选名单**：
- HeyGen（国内可用的国际方案）
- 出门问问（魔音工坊）或类似国内语音+口型方案
- 魔珐科技（Xmov）
- 相芯科技（FaceUnity）
- D-ID 或 DeepBrain AI
- 其他你搜到的国内/国外方案

### 二、开源模型调研

请调研以下开源方案的实际可用性：

- **Wav2Lip**（最知名的开源口型同步模型）
  - 实际效果如何？是否适合短剧场景？
  - 有没有优化的中文版本或变体？
  - 部署难度和硬件要求？
  
- **MuseTalk / SadTalker / VideoReTalking** 等新方案
  - 与 Wav2Lip 的对比
  - 是否支持中文？

### 三、短剧场景适配分析

针对短剧行业的特殊需求，请评估：
1. **画质要求**：1080P输出，口型区域不能有明显的模糊或伪影
2. **批量成本**：短剧一集10-15分钟，一部剧100集，每集2-3个角色需要换口型，总时长和成本估算
3. **人脸角度**：短剧演员经常侧脸、低头、快速转头，各方案对这些角度支持如何？
4. **多人场景**：同一画面中多个说话角色，能否选择性替换？

### 四、输出格式

请以结构化表格+详细分析的形式输出，每个方案给出：
- 适用场景（完全适合 / 部分适合 / 不适合短剧）
- 优缺点（3条以内）
- 推荐优先级（高/中/低）
- 如果能找到实际用户评价或测试视频链接，请附上

注明所有信息的来源链接，有官方文档优先引用官方文档。不确定的数据请标注"待验证"。
