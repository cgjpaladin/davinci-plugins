# vanilla-css-design-system 分析 — 对照 app.css

> 2026-05-14 研读

## Token 层级对比

| 层级 | vanilla CSS | 我们的 app.css | 差距 |
|------|------------|----------------|------|
| **原始值** | #6e0e50 等 | 无（直接写语义名） | — |
| **色阶** | --color-primary-50~900（10级） | 无 | ⚠ 缺 |
| **语义 token** | --helix-bg-primary, --helix-text-primary, --helix-border-primary | --bg, --surface, --text, --accent | 我们有语义但无底层色阶 |
| **交互状态** | --interactive-{default,hover,active,focus} | 无，hover色硬编码在各处 | ⚠ 缺 |

## 我们的问题

### 1. 没有色阶
```css
/* 当前: 扁平 */
--accent: #e8870a;
--accent-dim: #8a5000;

/* 缺乏: 深浅变化 */
--accent-dim → 比 --accent 深多少？hover 用什么？无明确规则
```

### 2. 交互色硬编码
```css
/* app.js 里到处散落 */
el.style.background='rgba(52,211,153,0.12)'  // green 12%
el.style.background=''                        // 清空
el.style.color='var(--text-bright)'           // 聚焦时
```
没有统一的 `:hover` / `:focus` / `:active` token。

### 3. 间距无体系
```css
--gap: 4px;
--pad: 6px;
--pad-lg: 8px;
```
没有 `--spacing-unit` 基数，无法等比例缩放。

## 改进方案（低风险，逐项推进）

### 阶段一：色阶补全（不改现有效果）
```css
:root {
  /* 新增：灰色阶 */
  --gray-50:  #fafafa;
  --gray-100: #f0f0f0;
  --gray-200: #e0e0e0;
  --gray-300: #c0c0c0;
  --gray-400: #909090;
  --gray-500: #707070;
  --gray-600: #555555;
  --gray-700: #3d3d3d;
  --gray-800: #282828;
  --gray-900: #1e1e1e;
  --gray-950: #151515;

  /* 语义 token 过渡到色阶 */
  --bg:        var(--gray-950);
  --surface:   var(--gray-900);
  --surface2:  var(--gray-800);
  --border:    var(--gray-700);
  --border-hi: var(--gray-600);
  --text:      var(--gray-300);
  --text-bright: var(--gray-100);
  --text-dim:  var(--gray-500);
}
```
> 效果：外观不变，但底层变量可追溯到色阶。

### 阶段二：交互态 token
```css
  --interactive-bg: rgba(52,211,153,0.12);  /* green tint */
  --interactive-focus-bg: rgba(232,135,10,0.08); /* accent tint */
```
> 集中定义，JS 里 `el.style.background='var(--interactive-bg)'` 替代硬编码。

### 阶段三：间距单位化
```css
  --space-unit: 4px;
  --gap:       var(--space-unit);
  --pad:       calc(var(--space-unit) * 1.5);
  --pad-lg:    calc(var(--space-unit) * 2);
```

## 不急着做的

- 10 级全色阶（目前用不到那么多色调变化）
- 语义命名大重构（--surface → --brand-surface 等，影响面太大）
- 字体 token 层级（目前只有两种字体，不需要复杂体系）
