# the-new-css-reset 分析 — 对照 app.css

> v1.11.3, 2024-08-25, 114 行

## 它的核心做法

```css
/* 1. 全局重置（核心） */
*:where(:not(html, iframe, canvas, img, svg, video, audio)) {
    all: unset;        /* 剥离所有浏览器默认样式 */
    display: revert;   /* 恢复 display 属性 */
}

/* 2. 边界盒 */
*, *::before, *::after { box-sizing: border-box; }

/* 3. 防 iOS 字体缩放 */
html { text-size-adjust: none; }

/* 4. 恢复光标 */
a, button { cursor: revert; }

/* 5. 去列表样式 */
ol, ul, menu, summary { list-style: none; }
```

## 对照我们的 app.css

| 规则 | new-css-reset | 我们的 app.css | 需要吗 |
|------|-------------|---------------|--------|
| `all: unset` | ✅ 全局剥离 | ❌ 只有 `margin:0;padding:0` | ❌ 不需要。我们已有完整样式体系，unset 等于自毁 |
| `box-sizing` | ✅ | ✅ | — |
| `text-size-adjust` | ✅ 防 iOS | ❌ | ⚠ pywebview 不需要，但浏览器 preview 可能有帮助 |
| `cursor: revert` | ✅ | ❌ | ⚠ 不影响功能，但可加 |
| `list-style: none` | ✅ | ❌ | ❌ 我们没有 `<ul>` / `<ol>` |
| `img max-size` | ✅ 防溢出 | ❌ | ⚠ 缩略图场景可能有图片，可加 |
| `input user-select` | ✅ | ✅（在 .file-section） | — |
| `::placeholder color` | ✅ | ❌ | ⚠ 可加——让 placeholder 继承父元素颜色 |

## 结论

我们的 app 是**受控的 pywebview 窗口**，不是内容网站。new-css-reset 的全面剥离（`all: unset`）会破坏我们的已有样式。

**唯一值得采纳的**：
```css
/* 浏览器预览兼容 */
html { text-size-adjust: none; }
/* 占位符颜色继承 */
::placeholder { color: inherit; opacity: 0.5; }
```

其他规则要么已有覆盖，要么不适用。当前的极简 reset 是合适的。
