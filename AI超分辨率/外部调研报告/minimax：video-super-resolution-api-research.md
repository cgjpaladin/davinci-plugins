## 三、逐方案详评

### 3.1 阿里云（视觉智能开放平台）

**API文档URL**：[视频超分API文档](https://help.aliyun.com/zh/viapi/developer-reference/api-video-super-resolution)

| 维度 | 详情 |
|------|------|
| **缩放倍数** | 固定2倍放大 |
| **输入限制** | 视频大小≤1GB；分辨率360×360~1920×1080；格式：MP4/AVI/MKV/MOV/FLV/TS/MPG/MXF |
| **输出格式** | H.264编码、MP4封装；码率可调（1~20 Mbps，默认10 Mbps） |
| **画质增强** | 基于深度学习细节推断，推理视频细节更真实 |
| **调用方式** | 异步任务（提交任务→查询结果两步） |
| **QPS限制** | 文档未明确标注 |

#### 价格体系

| 帧率档位 | 单价 | 1集(1.5分钟) | 100集(150分钟) |
|----------|------|--------------|----------------|
| ≤30fps | 0.4元/分钟 | **0.6元** | **60元** |
| 60fps | 0.8元/分钟 | **1.2元** | **120元** |

预付费资源包：50元/125分钟（无优惠），10万点以上有一定折扣

#### 优缺点分析

**优点**：
- 品牌背书强，阿里巴巴技术沉淀
- API成熟稳定，SDK支持完善
- 输出码率可自定义

**缺点**：
- 输入分辨率限制较严（最大1080p），不适合1080P→4K场景
- 价格相对较高
- 不支持4x放大

#### 短剧场景适配性：⭐⭐⭐（3/5）

适合720P→1080P场景，价格和画质尚可，但1080P→4K需另选方案。

### 3.2 火山引擎（视频点播-画质增强）

**核心文档**：
- [极智超清](https://www.volcengine.com/docs/4/165177)
- [画质增强修复](https://www.volcengine.com/docs/4/117971)
- [计费概述](https://www.volcengine.com/docs/4/65628)

| 维度 | 详情 |
|------|------|
| **缩放能力** | 支持超分辨率放大 |
| **综合增强** | 去噪、色彩增强、细节增强、SDR转HDR、智能插帧 |
| **处理方式** | 模板化转码（极智超清模板） |
| **价格模型** | 视频点播整体计费（转码+增强单独计费） |

#### 核心能力

火山引擎提供**画质增强修复**功能，综合使用：
- **智能超分**：提升分辨率
- **智能插帧**：提升流畅度
- **HDR**：色彩增强
- **极智超清**：基于人眼视觉系统特性优化

极智超清基于人眼视觉系统特性，针对视频场景、动作、内容、纹理等内容进行智能分析，综合使用视频处理增强算法和自适应转码算法，来优化视频主观质量并降低码率。

#### 计费说明

火山引擎视频点播采用**按量计费+资源包**模式：
- 基础转码：按输出时长和分辨率收费
- 画质增强：智能超分等能力需单独计费
- 推荐工具：视频点播价格计算器

#### 优缺点分析

**优点**：
- **已有AK/SK，零集成成本**
- 抖音同款技术，画质优化成熟
- 综合增强能力强，不只是拉分辨率
- 价格相对较低（豆包模型价格比行业低85%）

**缺点**：
- 超分API细节需进一步确认（文档分散）
- 需要区分转码费用和增强费用

#### 短剧场景适配性：⭐⭐⭐⭐⭐（5/5）

**首选推荐**。理由：已有火山引擎AK/SK、成本优势明显、抖音同款技术、人脸/字幕增强综合能力强。

### 3.3 腾讯云（数据万象-超分辨率）

**核心文档**：
- [超分辨率任务API](https://cloud.tencent.com/document/product/1545/65222)
- [画质增强](https://cloud.tencent.com/document/product/460/60333)
- [媒体处理费用](https://cloud.tencent.com/document/product/460/58120)

| 维度 | 详情 |
|------|------|
| **超分版本** | 基础版、增强版 |
| **计费方式** | 按输出视频时长收费（不同分辨率费用不同） |
| **增强能力** | 视频色彩增强、细节增强、SDR to HDR、去噪等综合增强 |
| **图像超分** | 支持2x/4x放大，图像超分0.006元/次 |

#### 能力矩阵

腾讯云提供**音画质重生**功能：
- 分辨率提升
- 视频去噪、轮廓修复
- 超分辨重建、细节增强
- 色彩增强
- SDR转HDR

#### 计费特点

| 计费项 | 说明 |
|--------|------|
| 超分辨率 | 按输出时长+分辨率收费 |
| 视频增强 | 按输入时长收费（通用计费项） |
| 色彩增强 | 独立计费 |

#### 优缺点分析

**优点**：
- 综合增强能力强（去噪+色彩+超分一体化）
- 基础版/增强版可选，灵活度高
- 腾讯视频"臻彩"技术背书

**缺点**：
- 价格文档分散，需进一步确认
- 计费逻辑较复杂

#### 短剧场景适配性：⭐⭐⭐⭐（4/5）

适合需要综合增强（去噪+色彩+超分）的场景，但价格确认成本较高。

### 3.4 七牛云（智能多媒体-视频超分）

**核心文档**：
- [视频超分API](https://developer.qiniu.com/dora/api/12508/video%20super%20resolution)
- [价格详情](https://www.qiniu.com/prices/dora)

| 维度 | 详情 |
|------|------|
| **缩放倍数** | **2倍或3倍**可选（`/superResolution/`参数） |
| **输入限制** | 仅支持≤1920x1080；华东区域处理 |
| **输出帧率** | 默认等于源帧率，范围1~60fps |
| **输出格式** | MP4（不支持m3u8）；H.264/H.265编码 |
| **超分模式** | `base`（基础版）、`faceEnhance`（人脸增强版） |

#### 价格体系（详细）

| 版本 | 1080p普帧 | 1080p高帧 | 2K普帧 | 4K普帧 |
|------|-----------|-----------|--------|--------|
| **基础版** | 0.8元/分钟 | 1.6元/分钟 | 1.6元/分钟 | 3.2元/分钟 |
| **人脸增强版** | 1.6元/分钟 | 3.2元/分钟 | 3.2元/分钟 | 6.4元/分钟 |
| **倍速基础版** | 2.4元/分钟 | 4.8元/分钟 | 4.8元/分钟 | 9.6元/分钟 |
| **倍速人脸增强版** | 4.8元/分钟 | 9.6元/分钟 | 9.6元/分钟 | 19.2元/分钟 |

#### 场景成本计算（1.5分钟/集）

| 版本 | 单集成本 | 100集成本 |
|------|----------|-----------|
| 基础版(1080p普帧) | **1.2元** | **120元** |
| **人脸增强版(1080p普帧)** | **2.4元** | **240元** |
| 倍速基础版(1080p普帧) | 3.6元 | 360元 |
| 倍速人脸增强版(1080p普帧) | 7.2元 | 720元 |

#### 优缺点分析

**优点**：
- **人脸增强版**专门优化人脸区域，非常适合短剧人物特写场景
- 价格透明，档位清晰
- 支持2x和3x放大（竞品多仅支持2x）
- 免费额度：每月20元多媒体处理服务

**缺点**：
- 仅华东区域处理
- 人脸增强版价格翻倍
- 倍速版价格较高

#### 短剧场景适配性：⭐⭐⭐⭐（4/5）

**人脸场景推荐**。人脸增强版非常适合短剧大量人物近景的特点，是七牛云的差异化竞争力。

## 五、最终推荐

### ⭐ 首选推荐：火山引擎

**推荐理由**：

1. **已有AK/SK，零集成成本**：用户明确提到已有火山引擎凭证，无需重新注册和配置。
2. **价格优势**：基于字节跳动技术积累，成本通常低于竞品。
3. **综合能力强**：不只是超分，还包括去噪、色彩增强、HDR等综合画质提升。
4. **极智超清技术**：基于人眼视觉系统特性，针对视频场景智能分析优化。
5. **可扩展性强**：配套视频点播、直播等全家桶服务。

**适用场景**：
- 720P→1080P（日常）
- 1080P→4K（偶尔需求）
- 综合画质提升（去噪+色彩+超分）

**建议**：联系火山引擎商务确认画质增强/超分的具体价格和技术细节。

---

### ⭐ 备选推荐：七牛云（人脸增强版）

**适用场景**：当短剧以人物特写为主、人脸质量要求极高时。

**推荐理由**：
- 人脸增强版专门优化人脸区域
- 价格透明（0.8-1.6元/分钟基础版）
- 支持2x/3x放大
- 国内运营经验丰富

**限制**：仅华东区域处理。
