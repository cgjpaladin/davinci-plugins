# 2026-06-02 — AI 字幕校对提示词全面重构

## 背景
交付自检 v2.5.0，AI 字幕校对板块（DS V4 Pro 单主力）。裁缝老师优化提示词 + 测试全链路。

## 模型性能参数
- DS V4 Pro：1M context / 384K max output / 500 并发
- Input $0.435/M, Output $0.87/M
- Thinking mode 默认开启，temperature 参数静默忽略
- JSON mode 可用，要求 prompt 含 "json" 关键词
- 1M context → 我们的全剧 1600 行仅占 <2%

## 关键改动

### llm_typo_check.py
- **删截断**：`_MAX_BATCH=300`、`_MAX_CONTEXT=2000` 全删，不截断不分批
- **参数优化**：
  - `max_tokens`: 4096→16384
  - `temperature`: 0.1→0.2（双跑并集）
  - 启用 JSON mode `response_format={"type":"json_object"}`
- **去重/分批死代码清理**
- **CPL 透传**：`timeline.GetSetting()["limitSubtitleCPL"]` → AI 提示词动态注入
- **char_list 移除**：不再用 Python 解析人物名，AI 自己读剧本小传
- **提示词重构**：
  - 规则从 10 条精简到 9 条（删「数字转中文」）
  - 输出格式从片段改整句（original/correction 写全文）
  - 断句规则重写：只报词语被切，不报语法断点；CPL 约束；两行用 `｜` 分隔
  - 真实地名：系统词典检出后 AI 标注「应替换为架空地名」
  - 违禁词：习近平 correction 写「请结合剧情自行判断」
  - 常见错别字：加 14 组（那/哪、做/作、代/带等）
  - JSON 示例扩展到 12 条，含多 reason
  - 去掉了「必须输出 JSON」的吼叫提示
  - 多 reason 支持（逗号分隔）
- **双跑机制**：temp 0.2 跑两次取并集去重，P1 抓明显错误，P2 补断句边缘 case

### llm_providers.py
- DS V4 Pro 关闭 thinking mode：`extra_body={"thinking":{"type":"disabled"}}`
- 超时：90s→300s
- `response_format` 参数透传链路
- 删除千问/智谱/Flash 降级 provider，仅保留 DS V4 Pro 单主力

### check_core.py
- 所有字幕检测函数改为仅扫 ST1（4 处 `for si in range(1, subtitle_count + 1)` → `range(1, 2)`）

### ui.py
- AI 校对字幕采集仅扫 ST1
- CPL 读取并透传

### 新增全局 dict
- `交付自检工具/dicts/cities_cn.txt`：390+ 中国城市名（来源 GitHub `public-wheels/china-cities`），走系统 censor 检测链

### 工具脚本
- `/tmp/test_one_round.py`：ST1-only、因 CPL 透传、Pass 标记 P1/P2、reason 多值校验
- `/tmp/test_duanju.py`：内联断句测试，不走达芬奇
- `/tmp/syscheck.py`：系统规则检测（无 AI）
