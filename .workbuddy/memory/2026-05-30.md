## 修复清单（按发生顺序）

### P0 — 个人版无法运行
- **Python 3.9 TypeAlias 兼容**：dftt_timecode 加版本判断，3.10+用标准库，3.9 fallback `TypeAlias = type`
- **壳缺执行权限**：`cp` 不保留 +x，达芬奇不显示。install.command 加 `chmod 755`
- **安装目录 root 不可写**：install.command 加 `chown $(whoami)`
- **Python Framework 检测**：达芬奇 macOS 要求 python.org Framework 安装，Xcode CLT 的不行。install.command 自动检测+下载 67MB pkg

### P0 — 个人版门锁死
- **门评估独立于 track_structure**：ui.py 加 `IS_PERSONAL` 守卫，个人版强制四门全开

### P0 — API Key 链断裂（三层）
- **key 名不匹配**：`.env` 写 `DEEPSEEK_KEY`，提供商找 `DEEPSEEK_API_KEY` → 统一改
- **\_get_key 先读文件不读 env**：llm_providers 改为 `os.environ` 优先
- **\_read_env_key 同样问题**：script_parser 改为 `os.environ` 优先
- **SSL 证书缺失**：两台文件 `urlopen` 无 `_create_unverified_context()` → llm_providers + script_parser 全加

### P0 — pycache 缓存旧代码
- **每次改代码不清缓存**：远程 pycache 导致旧 `.pyc` 挡路，install.command 加 `importlib.invalidate_caches()`
- **typo 缓存不含模型名**：`check_typos_cached` 哈希键加模型名，换模型自动失效

### P1 — LLM 模型太弱
- **v4-flash → v4-pro**：flash 10 次抓不到"不饶人"，pro 一次命中。DeepSeek 官方推荐高精度用 pro

### P1 — LLM same_show 太保守
- **prompt 改**："明显不是"→"人名一个都找不到"；"不确定优先 false（宁可误报）"

### P1 — PDF 无法解析
- **pypdf 未打包**：build_personal.sh 加 pypdf 完整模块

### P1 — 前置 5% 匹配拦断
- **用户不要省钱**：去掉多余前置校验，让 LLM 自己判断 same_show

### P2 — 安装脚本改进
- 错误日志写入文件并在弹窗显示
- 安装完多余 `open` 已删
- .env 中文注释改英文避免编码错误

### P2 — SSH 限流
- `.ssh/config` 加 ControlMaster 连接复用
