# 2026-06-10

## 许可证系统 v3 重构（凌晨 01:53 ~ 04:01）

### 核心改动
- **试用纯本地化**：`init_trial()` 写本地凭据，不调服务端。30 天一次性。
- **状态机三态**：待售→待激活→已激活。gen_key 默认待售，admin 手动改待激活，用户激活→已激活。
- **砍心跳**：删除 `handleHeartbeat`、`heartbeat()`，仅保留启动时 `verify_status` 校验。
- **停用回归试用**：停用后写过期/恢复试用凭据，不删文件。试用天数冻结（存剩余秒数）。
- **启动时吊销校验**：`verify_status` 检查激活码+指纹是否仍匹配。被吊销→写过期凭据（非清空），防止删除重拿 30 天。
- **表结构简化**：删除创建时间列，激活码、状态、机器指纹、激活时间（首次激活写）、用户、备注。

### UX 改进
- 输入校验：每格必须 4 位 `[A-Z0-9]{4}`、汉字/符号拦截
- 部分输入提示：`请完整输入 12 位激活码`
- API Key 格式校验：sk-/cli_/长度
- 连接中提示：`⏳ 正在连接服务器…`（橙色）
- 人性化错误消息从服务端直出，客户端零翻译
- 黄字=许可证售卖，白字=功能指引
- 用户输错码不记入错误计数器（`_activation_failed` 机制）
- 配置页失败时不自动关闭
