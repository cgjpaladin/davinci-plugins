## 更新步骤

### 1. 解压覆盖

将 `创壹特供版_增量更新.zip` 解压到上次的项目目录，覆盖同名文件。

文件结构需保持：
```
项目根/
├── shared/
│   └── naming_createone.py    ← 覆盖
├── 批量命名工具_创壹特供版/
│   ├── app.js                 ← 覆盖
│   ├── app.css                ← 覆盖
│   ├── renamer_web.html       ← 覆盖
│   ├── renamer_web.py         ← 覆盖
│   ├── build.sh               ← 覆盖（macOS）
│   ├── build_win.bat          ← 覆盖（Windows）
│   └── version_info.txt       ← 新增
```

### 2. Windows 打包

```cmd
cd 批量命名工具_创壹特供版
build_win.bat
```

产物在 `dist/批量命名工具-创壹特供版/`，发给用户。

### 3. 360 误报处理

本次更新已加反误报参数（`--strip --noupx --version-file`）。如果还报毒，右键 360 托盘 → 文件白名单 → 添加 exe 所在文件夹。

## 本次更新内容

### 审查模式
- 单击缩略图 → 弹窗预览视频/图片（原双击）
- 空格键：有选中文件时打开审查
- × 关闭按钮在标题栏左侧
- 上一个/下一个不会关闭弹窗（原地替换）
- 视频控制栏：播放/暂停、进度条拖拽、音量、速度 0.5x/1x/2x、逐帧、全屏、截图
- 键盘：Space 暂停、← → 跳 2 秒、`, .` 逐帧、J 减速 K 暂停 L 加速、Ctrl+← → 切文件

- 按钮：action-bar 最右侧「导出为表格」

- 列：缩略图 / EP / SC / SH / TK / 描述 / 类型 / 作者 / V / 状态 / 文件名
- 缩略图按实际比例嵌入，补零不掉

### 修复
- ffmpeg + ffprobe 已打包进 app（用户不需要自己装）
- 文件名双下划线修复（`build_filename` 空字段过滤）
