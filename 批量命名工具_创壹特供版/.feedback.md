# 创壹特供版 · 反馈记录

### 2026-05-27 反馈

#### 1. 命名体系对齐
裁缝老师："忽略之前的需求，我重新给你新的命名体系"
→ 沉淀为：开发前必须先对齐命名格式，不做假设

#### 2. 只要表格版
裁缝老师："只要表格版，旧的卡片版不需要特供"
→ 沉淀为：初始写卡片版是方向错误，先问清楚形态

#### 3. 制作者英文 only
裁缝老师："制作者只要英文"
→ 沉淀为：字段过滤规则是用户需求的一等部分，不能沿用原版

#### 4. SH 分隔符不能用 /
裁缝老师："SH 用 / 分隔，文件名会崩"
→ 沉淀为：文件名分隔符必须文件系统兼容，`/`→`-`

#### 5. AIVID desc 无提示
裁缝老师："视频无需输入描述，但没有提示，用户会迷惑"
→ 沉淀为：不可编辑字段必须有内联说明文字

#### 6. 00 无意义
裁缝老师："很多地方支持输入 00，无意义"
→ 沉淀为：数字输入 blur 补零应排除 0，commit 过滤 00

#### 7. TK 导致不给重命名
裁缝老师："视频都填完了不让重命名"
→ 沉淀为：`_REQUIRED_KEYS` 不能含自动计算字段（tk）

### 2026-05-28 反馈

#### 8. 导出按钮太大
裁缝老师："导出为表格按钮太大，跟重命名和撤销按钮风格对齐"
→ 沉淀为：新增按钮样式必须对齐现有同类按钮

#### 9. 导出没让选路径
裁缝老师："导出时仅提示成功，没让我选路径，也没让我命名"
→ 沉淀为：文件导出必须有原生保存对话框

#### 10. ffmpeg 不能要求用户装
裁缝老师："mac 用户显然没装 ffmpeg，你不能让他自己装吧"
→ 沉淀为：依赖的二进制文件必须打包进 app（`--add-binary`）

#### 11. xlsx 打开空白
裁缝老师："打开后只看到第一行冻结，点进单元格没数据显示"
→ 沉淀为：不要手拼 xlsx XML（inlineStr macOS 不兼容）。用 openpyxl

#### 12. 缩略图压扁
裁缝老师："缩略图被压扁了"
→ 沉淀为：图片导出必须读实际尺寸算比例

#### 13. 补零失效
裁缝老师："所有的补零全部失效了"
→ 沉淀为：数字存为文本（`zfill`），不能存 int（丢前导零）

#### 14. 序号和源文件名不需要
裁缝老师："序号和源文件名在表格中不需要了"
→ 沉淀为：导出列由用户需求决定，不做假设

#### 15. 新文件名包括扩展名
裁缝老师："扩展名要跟实际文件一模一样"
→ 沉淀为：扩展名从实际文件读取，不靠类型推断

#### 16. 导入逻辑确认
裁缝老师："无扩展名应该完全无法导入吧？"
→ 确认：`MEDIA_EXT` 已正确拦截，死代码已清除

#### 17. 视频播不了
裁缝老师："视频和图片还是看不了，要彻底，要深度，不要打补丁"
→ 沉淀为：不要用 bottle 静态文件 / file:// URL。用 JS API 直传 base64 → Blob URL

#### 18. Prev/Next 闪烁
裁缝老师："每次上一个，下一个，都会退回原来界面，再开一次审阅模式"
→ 沉淀为：导航应原地替换内容不关弹窗

#### 19. 左右键跨度太大
裁缝老师："左右键 5 秒太多了，大多数视频也就 15 秒"
→ 沉淀为：快捷键时间跨度要适配实际素材长度

#### 20. 导出按钮文字和 emoji
裁缝老师："导出按钮要写'导出为表格'，不要 emoji"
→ 沉淀为：按钮文字用中文描述，不用 emoji
