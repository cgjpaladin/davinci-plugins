# 创壹特供版 · 反馈记录

### 2026-05-27 反馈

#### 1. 命名体系对齐
裁缝老师："忽略之前的需求，我重新给你新的命名体系"
→ 沉淀为：开发前必须先对齐命名格式，不做假设

#### 2. 只要表格版
裁缝老师："只要表格版，旧的卡片版不需要特供"
→ 沉淀为：初始写卡片版是方向错误，先问清楚形态

#### 3. 制作者英文 only
裁缝老师："制作者只要英文"
→ 沉淀为：字段过滤规则是用户需求的一等部分，不能沿用原版

#### 4. SH 分隔符不能用 /
裁缝老师："SH 用 / 分隔，文件名会崩"
→ 沉淀为：文件名分隔符必须文件系统兼容，`/`→`-`

#### 5. AIVID desc 无提示
裁缝老师："视频无需输入描述，但没有提示，用户会迷惑"
→ 沉淀为：不可编辑字段必须有内联说明文字

#### 6. 00 无意义
裁缝老师："很多地方支持输入 00，无意义"
→ 沉淀为：数字输入 blur 补零应排除 0，commit 过滤 00

#### 7. TK 导致不给重命名
裁缝老师："视频都填完了不让重命名"
→ 沉淀为：`_REQUIRED_KEYS` 不能含自动计算字段（tk）
